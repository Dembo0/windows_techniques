# Windows Malware Delivery & Execution Analysis
Репозиторий содержит технические разборы (write-ups) и исследования векторов первичного доступа и выполнения вредоносного ПО под ОС Windows: **HTML/SVG Smuggling** и **DLL Side-Loading**.

## ⚠️ Disclaimer
Материалы репозитория представлены исключительно в исследовательских и учебных целях (Cybersecurity Research & Defensive Engineering).
